# 自动任务派发

启动 FastAPI 后，每 5 秒执行一次调度。有效预约生成 pending 任务；按预约时间排序，为已连接 control WebSocket、启用且空闲的车辆批量分配任务。无可用车辆时保持等待，前端通过现有查询接口获取状态。

车辆连接时补发当前 running 任务，并尝试分配等待任务。收到 task_completed 后，同步任务、快递、预约和车辆状态，再分配下一单。重复完成回传不会释放正在执行其他任务的车辆。

预约改期和地址修改同步到 pending 任务；取消预约会取消待派发任务并解除快递绑定。任务开始执行后不允许修改预约。创建预约校验快递归属并拒绝重复有效预约。

管理员仍可通过 POST /api/dispatch/run 立即执行一次调度。

当前 WebSocket 连接保存在进程内，部署时使用单 worker：

```sh
uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 1
```

重连会重发相同 task_id，车端必须以 task_id 去重。当前协议没有持久化的接收确认，发送成功仅表示 WebSocket 写入成功。地址仍使用现有任务字段，不在本次改动中加入自动地理编码。调度沿用原有行为，预约时间作为排序和预计完成时间，不作为开始派发的时间门槛。
